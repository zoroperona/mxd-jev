## 用户录像实验

输入为本地 `1790438198296.mp4`，约 80.2 秒，1708 × 998。按每秒 5 帧采样，共分析 401 帧，裁剪窗口标题栏后统一到 1440 × 810。

| 指标 | 首轮样本 | 多样本版本 |
| --- | ---: | ---: |
| 角色与血蓝同时可识别的帧 | 263 / 401 | 291 / 401 |
| 上述覆盖率 | 65.6% | 72.6% |
| 至少检测到一个怪物候选的帧 | 93 / 401 | 234 / 401 |

初始样本来自约 40 秒画面；新增样本来自约 15、55、75 秒画面，包含不同角色名牌背景和怪物头部姿态。样本与评估使用同一录像，**不是独立测试集**。怪物计数只说明检测器输出，不表示真阳性；覆盖率不表示准确率、召回率或刷怪成功率。尚未完成逐帧人工标注。

本地输出在 `outputs/video-review-final/`，包括标记视频、逐帧状态/建议动作日志和汇总；个人素材与校准配置不上传到代码仓库。

实验还修复了多角色样本的去重问题：同一名牌的不同身体偏移应合并为一个候选，而不是被误判为多个角色。已加入回归测试。

**结论：可用于继续校准和实机观察，但尚不满足稳定挂机验收。** 角色名牌被遮挡/变色时仍可能丢失；怪物模板也受动画影响。当前实现检测丢失就暂停，不用旧坐标继续攻击。
